<b><a href="https://github.com/VioletActual/insurance-quote-manipulation-detection">Behavioural Fraud Detection: Motor Insurance Quote Manipulation</a></b>

Detects suspicious quote-manipulation journeys, then uses an LLM to write analyst-ready, evidence-grounded explanations for each flagged case. FastAPI service (5 endpoints plus interactive console), versioned prompts with an automated promotion gate, LLM-output scoring validated against 60 human labels, MLflow tracking, Docker, 68 tests in GitHub Actions CI.
